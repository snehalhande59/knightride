KNIGHT RIDERZ RIDING CLUB - FRONTEND DEMO

FILES
- index.html       Homepage
- about.html       About KRRC
- rides.html       Rides & Expeditions
- gallery.html     Photo & Video Gallery
- merchandise.html KRRC Merchandise
- join.html        Membership enquiry

HOW TO RUN
1. Extract this ZIP folder.
2. Double-click index.html to open in Chrome.
3. Use the navigation menu/buttons to open the separate HTML pages.
4. Keep all files together in the same folder.

NOTES
- Original supplied KRRC logo is embedded in the HTML files.
- Images load from Unsplash, so an internet connection is required.
- This is frontend-only. The membership form only shows a demo confirmation.
- Sample ride data and merchandise prices are illustrative and must be verified.
